# Default exclusion patterns for /assess-repo.
#
# One glob pattern per line (fnmatch-style, matched against the path relative
# to the repo root, POSIX separators). Blank lines and lines starting with #
# are ignored. Prefix a pattern with "generated:" to mark it as generated code
# specifically — these are still excluded from all codebase.* counts like
# every other exclusion, but are ALSO tracked separately so
# codebase.generated_loc_pct can report how much of the raw repository is
# generated, as opposed to vendored/build-output/binary noise.
#
# Extend this per-repo by passing your own file and letting the skill merge it
# with this default list — never edit this file to special-case one repo.
